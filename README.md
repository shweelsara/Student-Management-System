Student Management System

A full-stack web application for managing student information.

📌 About The Project

Student Management System is a web application that allows users to manage student records easily.

The application provides a simple and responsive interface for adding, searching, editing, and deleting student information.

Student data is stored permanently in MongoDB through a Node.js and Express.js backend.

🚀 Features

- Add new students
- Edit student information
- Delete students
- Search by student name
- Search by department
- Search by email
- Form validation
- Total students counter
- Responsive design
- MongoDB database
- REST API
- Node.js backend
- Express.js server

🔌 API Endpoints

Get all students

GET /api/students

Add a student

POST /api/students

Update a student

PUT /api/students/:id

Delete a student

DELETE /api/students/:id

▶️ How To Run

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd Student-Management-System

3. Install dependencies

npm install

4. Start the server

node server.js

5. Open the application

http://localhost:3000
